# 04 — 週計劃（倒數排程）

> 開始：**2026-10-26（W1，星期一）** ｜ 考試週：**W56（2027-11-15 起）**，以 HKIE 2027/28 公告為準
> 基本預算：**6 小時/週**；聖誕 / 農曆新年兩個 buffer 週 3 小時；4 個 full mock 週 8 小時（需要請假）
> 進度記錄：`progress-tracker.csv`（每週日晚填 `hours_done`、`status`、`notes`）

---

## 1. 每週節奏（6 小時版本）

| 時段 | 時數 | 用途 |
|---|---|---|
| 平日晚 ×2（例如二、四） | 2 × 1.5 h | 讀 code / 參考書、整理筆記 |
| 週末一節 | 3 h | **一條完整 hand calc 或 sketch**（一定要落手做，唔好淨係睇） |
| 通勤 / 午飯碎片時間 | （唔計入） | 睇 rules of thumb 筆記、MCQ 自擬題 |

規則：
- 每週末用 10 分鐘填 tracker；連續 2 週 `hours_done` 少過計劃 70% → 喺下一個 buffer 週補，或者減一個練習。
- Mock 週（W42、W46、W49、W52）建議請 **1 日 annual leave** 做足 7.5 小時，平日晚嘅 0.5 小時用嚟自我批改。

## 3. 補足實務經驗嘅方法（同溫書並行）

呢部分**唔計入 6 小時**，盡量用工作時間或者公司安排做。

### 3.1 公司 building 組（最高優先）
| 做法 | 時間 | 產出 |
|---|---|---|
| **W1 約 building 組 manager / director 傾**：講明你準備 HKIE Structural，問可唔可以 (a) 參加佢哋嘅 design review、(b) 睇過往項目嘅 calc package 同 drawings、(c) 有機會借調 / 兼做一個 building 項目 | W1 | Shadow 安排 |
| **每月 1 次 design review / internal meeting 旁聽** | W4 起 | 記錄 scheme 點揀、點解揀 |
| **讀 3 套真實 building calc package**：(1) 有 transfer plate 嘅住宅；(2) 有 basement 嘅商業 building；(3) steel / composite building | Phase 1–2 | 每套寫 1 頁「load path + lateral system + foundation」摘要 |
| **借一套 BD submission（superstructure）**，用 ADV-33 checklist 逐項對 | W37 | 理解 BD 想睇乜 |
| **爭取做一個 building 項目嘅部分工作**（就算係 checking、一部分 element design） | 最好 Phase 2 內 | Interview 用嘅 building 例子 |
| 搵一位 **HKIE Structural member 做 mentor**：批改自擬項目同 mock | W17 起 | 每份 mock 都有 examiner 角度 comments |

### 3.2 Site visit
| 階段 | 睇乜 | 對應缺口 |
|---|---|---|
| Foundation / basement | Bored pile、diaphragm wall、ELS strut、top-down | G6 |
| Transfer plate 澆注 | 分層澆注、propping、reinforcement congestion | G3、G12 |
| Typical floor cycle | Formwork、jump form core、tower crane tie-in | G12 |
| Steel / composite building | Erection sequence、connections、fire protection | G10、G12 |
| MiC / precast 項目 | Module 安裝、connection | G14 |
> 目標：Phase 2 期間每月 1 次。可以透過公司項目、HKIE Structural Division / HKIE-ST technical visits 安排。

### 3.3 自做完整 building scheme 練習
- **W34–W36**：自擬 brief（例：25 層 office + 3 層 podium（有 transfer）+ 2 層 basement，地盤一邊近斜坡、一邊近 MTR protection zone）。
- 做齊：兩個 distinct schemes → 比較 → calcs（transfer、core、foundation、basement wall）→ dimensioned framing plans → method statement。
- 交 mentor / building 組同事 review，再按 comments 改一次。
- 呢份嘢之後亦可以用喺 **interview** 講你點樣自己補 building 知識。

### 3.4 其他
- HKIE Structural Division 嘅 seminars / CPD（亦都計 CPD 時數）。
- BD e-learning：Wind Code 2019 briefing videos（W3）。
- 同 building 組同事食飯時問「呢個 project 嘅 lateral system 係乜、點解咁揀」— 低成本、高回報。
