## 1. 一句總結

- **17 年都有一條 bridge 題**（2012 年仲有兩條），全部要用 **SDM（Structures Design Manual for Highways and Railways）** 做 loading 同 wind。你 HyD footbridge 背景喺呢條題有最大優勢。
- Building 題每年 3–5 條，題材集中喺：**大跨（hangar、展覽館、商場 skylight）、transfer（上下柱唔對位）、鄰近 MTR / 歷史建築 / 斜坡嘅限制、basement + uplift**。
- **2023 年之後冇再出 high-rise**；A&A（改建加建）2022、2023 連續出咗兩年。
- 時間：2009–10 年 5 小時 → 2011–23 年 6 小時 → **2024 年起 6.5 小時**（12:00–18:30）。

## 3. 題目點問：分數結構

### 3.1 Building 題（以 2025 為例）

| 部分 | 要求 | 分數 |
|---|---|---|
| 1(a) | 兩個 distinct and viable 嘅 structural scheme，附 sketch，講 load path、stability、foundation，最後建議一個 | 30 |
| 1(b) | Wind load（Wind Code 2019）+ overall stability（overturning、sliding、uplift） | 10 |
| 2(c) | 建議 scheme 嘅主要構件 calcs（transfer、long-span、column、slab） | 15 |
| 2(d) | Dimensioned framing plans、sections、elevations | 20 |
| 2(e) | 關鍵 connection / detail | 10 |
| 2(f) | Foundation design calcs | 5–6 |
| 2(g) | Foundation layout plan | 5–6 |
| 2(h) | Construction programme 或 method statement | 3–5 |

**1(b) 嘅標準字眼（2022 年起）**：Ze = Z、overload factor 1.4、唔使考慮 torsion 同 across-wind。

### 3.2 Bridge 題

| 部分 | 要求 | 分數 |
|---|---|---|
| 1(a) | 兩個 distinct 嘅 bridge scheme（deck 型式、span arrangement、pier、foundation、施工方法），建議一個 | 30 |
| 1(b) | Wind（SDM）：橫向、縱向、uplift，計 bearing / pier 力 | 10 |
| 2(c) | Deck、pier、bearing 嘅主要 calcs | 20 |
| 2(d) | General arrangement、cross-section、**bearing articulation plan** | 20 |
| 2(e) | Method statement（臨時交通管理、possession、吊裝） | 10 |
| 2(f) | Programme | 10 |

Bridge 題嘅 method statement + programme 佔 **20 分**，係 building 題（3–5 分）嘅幾倍，正好係做過 HyD 工程嘅人嘅強項。

## 4. 評分規則（非官方，GuideBook gb1）

### 4.1 成份卷 FAIL

- 淨係得一個 superstructure scheme，或兩個唔夠 distinct，或其中一個唔 viable。
- 題目要求兩個 foundation scheme 而冇 / 唔 viable。
- **Major non-compliance**：column 入咗 column-free zone、column spacing 或 clear width 唔夠、用咗題目禁止嘅做法（例如 inverted roof）、foundation 入咗 MTR protection zone。

### 4.2 扣分

| 項目 | 扣分 |
|---|---|
| Headroom 唔夠、漏 loading provision、FRR 唔夠、cantilever 超過限制、structure 入咗 atrium void | 每項 −5（兩個 scheme 都犯只扣一次） |
| 冇 functional framing plan | −10 |
| 冇講 loading assumption、load path（包括 wind）同 stability | −10 |
| 冇清楚建議同原因 | −5 |
| 1(b) 冇乘 1.4 overload factor 又冇解釋 | −3 |

1(b) 要寫明引用 Wind Code §2.2 同 §3.1。Solution 用嘅 stability FOS：overturning ≥ 1.5、sliding ≥ 1.5、uplift ≥ 1.1。

### 4.3 Method statement 同 programme（examiner report）

- 寫清楚施工順序：site set-up → condition survey + monitoring → ELS / 樁 → pile cap → basement → superstructure。
- 隔籬有 MTR 或舊樓：挖掘方法、dewatering、震動控制、monitoring trigger level。
- 地下水位高：sheet pile / pipe pile + grout curtain。
- Programme 要由 plan approval、consent to commence 排到 OP。

## 5. 要準備同展示乜

### 5.1 答題框架（Section A，參考 Exam Mastery）

1. Introduction：一兩句講題目重點。
2. **Design appraisal 表**：逐個 client requirement / site constraint → 對設計嘅影響。
3. **Scheme options 表**：materials、grid、vertical transfer、lateral system、beam-slab、foundation，兩個 scheme 最少有 3–4 樣唔同。
4. 每個 scheme：description → functional framing plan → gravity 同 lateral load path → feasibility sizing → progressive collapse → basement → foundation。
5. **Recommendation 表**：local practice、材料供應、flexibility、durability、使用空間、foundation 成本、速度。

### 5.2 出 scheme 嘅實用規則

- 先列晒每層 headroom 同可用 structural zone；zone 特別大嗰層通常係叫你做 transfer。
- RC 約 900 mm structural zone → grid 10–12 m。
- Column 估算：RC 4–8 層 1 m、8–16 層 1.5 m、16–24 層 2 m；composite 4–12 層 1 m、12–20 層 1.5 m。
- 荷載估算：RC 每層 10 kPa、composite 7 kPa。
- Vertical transfer 六種（gb v32）：唔 transfer、transfer beam / truss、transfer plate、inclined column、roof truss + hanger、Vierendeel。
- Framing plan：graph paper 1:500，畫一個完整 typical bay，用顏色 legend。

### 5.3 Bridge 路線準備清單（建議主攻）

- [ ] SDM loading：LM1、LM3 / SV196、pedestrian load、footbridge vibration（steel code 2026 amendment：vertical ≥ 3 Hz；lateral mode < 1.5 Hz 先要 check）
- [ ] SDM wind：橫向、縱向、uplift；bearing 反力
- [ ] Bearing articulation：fixed / guided / free 點樣排、expansion joint 位置
- [ ] Deck 型式比較：steel box、steel truss、precast prestressed beam、in-situ box girder；ramp ≤ 8%
- [ ] Pier 同 foundation：bored pile、socketed H-pile、mini-pile（地方細）
- [ ] 吊裝方法：大吊機、整段 lift-in、incremental launching
- [ ] TTM 同 possession：晚間封線、週末 railway possession、航道封航
- [ ] Programme：design → TTM / XP 批核 → 樁 → pier → deck 吊裝 → finishes

### 5.4 Building 路線準備清單（後備 + MCQ / interview 都要用）

- [ ] 低至中層 RC / composite frame + core，有 transfer 嘅題型
- [ ] 大跨鋼屋頂：truss、space frame、portal frame + crane
- [ ] Basement：ELS、uplift（tension pile / 加重）、地下水
- [ ] 鄰近限制：MTR protection zone、Scheduled Area No. 3、斜坡、歷史建築
- [ ] A&A：現有結構評估、APP-117 wind 檢查、加層對 foundation 嘅影響

### 5.5 MCQ 範圍（Trial V1 / V2）

- 結構概念：load path、transfer system、SFD / BMD、punching、anchorage
- 施工：拆模同 back-propping、pile integrity vs load test、鋼結構安裝穩定
- 法規程序：plan approval → consent → OP、contract administration
