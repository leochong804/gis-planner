|---|---|---|---|---|
| **Concrete** | Code of Practice for Structural Use of Concrete **2013 (2020 Edition)**，2020 年 12 月頒佈（APP-142） | Feb 2022、Jun 2023、**Apr 2024** | Basis of design、durability & fire cover、analysis、beams / slabs / flat slab / punching、columns / walls、ductility detailing、deep beams / corbels、detailing rules | ✅ |
| **Steel** | Code of Practice for the Structural Use of Steel **2011 (2023 Edition)**，2023 年 3 月（APP-168；已合併 2016、2021、2023 嘅 amendments） | **Apr 2026** amendments（ultra-high-strength steel、唔同 grade 焊接、building acceleration limits、steel-framed structural systems）— 生效狀態未確認 | Cross-section classification、beams / LTB、columns、frame stability（second-order、notional forces）、connections、composite construction、serviceability / vibration | ✅ / ⚠️（2026 amendment 生效狀態） |

| **Foundations** | Code of Practice for Foundations **2017 (2024 Edition)** | — | Pile types、allowable capacities、pile groups、negative skin friction、raft / shallow foundation、uplift；Code 明言**現時唔包 seismic design** | ✅ |

| **Fire Safety** | Code of Practice for Fire Safety in Buildings **2011 (2024 Edition)**（EMSD 網頁有引用；BD 原文未直接打開） | — | FRR、structural fire protection、concrete cover | ⚠️ |

| **Site Supervision / Demolition / 其他** | 未有搜尋核實 | — | Interview 同 construction 題可能用到 | ❌ |

### 考試用法提示
- 考試 **open book**（見 README）。建議**將 Concrete、Steel、Wind、Foundations、DIL 印出嚟 / 用平板**，貼 tab，自製 index（W41 做）。
- 所有 code 都用**最新 consolidated edition + amendments**；考試大約喺 2027 年 11 月，如果 2027 年內 BD 再出新 edition / amendments（例如 steel 2026 amendments 生效），**以考試當屆 guidance notes 指明嘅版本為準**。

## 2. 法例

| 法例 | 狀態 / 重點 | 狀態 |
|---|---|---|
| **Buildings Ordinance (Cap. 123)** | 主體法例；AP / RSE / RGE / RC 角色同責任、plan approval、consent to commence | ✅（概念） |
| **Building (Construction) Regulation**（新） | 取代 1956 年版嘅 Building (Construction) Regulations (Cap. 123B)，共 12 Parts + Schedule，**改為 performance-based**：materials、dead / imposed / wind loads、design methodology、strength / serviceability / stability、construction methods（Parts 2–4）；site investigation、foundations、retaining walls、bulk excavation（Parts 5–7）；external walls、cladding（Parts 8–9）。有政府文件引用為 Cap. 123Q | ⚠️（生效日期同 Cap. 號未直接核對，W1 上 eLegislation 確認） |
| Building (Administration) Regulations (Cap. 123A) | Submission 程序 | ❌（未有搜尋） |
| Building (Planning) Regulations (Cap. 123F) | GFA、storey height 等（同 APP-5 transfer plate 豁免 GFA 有關） | ❌（未有搜尋） |

## 3. PNAP / APP / ADV（與 structural 相關）

| 編號 | 內容 | 點解要讀 | 狀態 |
|---|---|---|---|
| **APP-5** | Height of Storeys — 包括 **transfer plate**：符合尺寸限制可以唔計 GFA；domestic ≤ 40 層：厚度上限 = typical storey height；較高 domestic / non-domestic：上限 4.5 m；plate 面積有上限；BS zone 唔計入厚度但要預留 maintenance access | Transfer plate scheme 嘅實際限制；Section A 構思時要知 | ✅ |
| **ADV-33**（Appendix B3） | Checklist for Superstructure Plan Submissions — 要求識別 **major transfer members**（failure would induce cumulative instability，例如 transfer plate）；wind 下 lateral deflection / acceleration 要 check；要有 wind load 總結同 foundation level lateral force equilibrium | 等於 BD 心目中一份 building structural submission 要有乜 — **直接當 Section B checklist 用** | ✅ |
| **ADV-36** | Modular Integrated Construction — modular units 組成嘅 building 要有足夠 stability 抵抗 wind 同其他 lateral loads | MiC 題目 / interview | ⚠️（來源為 Scribd 副本，日期 2025-07-18） |
| **APP-142** | 頒佈 Concrete Code 2013 (2020 Edition) | 版本參考 | ✅ |
| **APP-168** | 頒佈 Steel Code 2011 (2023 Edition) 同 amendments | 版本參考 | ✅ |
| **APP-174** | Precast Code 2016 amendments（Nov 2020、Jun 2026）| 版本參考 | ✅ |
| Basement、ELS、foundation、site supervision 相關 APP | 未有逐個核實編號 | W27–W28 讀 basement / ELS 時，去 BD PNAP index 搵 | ❌ |
